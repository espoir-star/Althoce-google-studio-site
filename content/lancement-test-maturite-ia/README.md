# Lancement du test de maturité IA

Page : `https://althoce.com/test-maturite-ia/`. Conception : `docs/test-maturite-ia/conception.md`.

## Contenu de ce dossier

| Fichier | Usage |
|---|---|
| `linkedin-post.md` | Post de lancement, premier commentaire et variantes d’accroche |
| `gbp-post.md` | Post Google Business Profile |
| `article-blog-brouillon.md` | Article d’appui pour le blog, à passer dans la chaîne de publication habituelle avec sa couverture |

## Ordre conseillé

1. **Avant d’annoncer** : passer le test soi-même, puis envoyer une demande d’échange avec ses propres coordonnées pour vérifier qu’elle arrive dans l’outil commercial (`docs/test-maturite-ia/webhook.md`).
2. **Jour du lancement** : demander l’indexation de la page dans la Search Console, publier le post LinkedIn (mardi ou jeudi, 8 h à 10 h), puis le post Google Business Profile.
3. **Dans les deux semaines** : publier l’article d’appui, qui renvoie vers le test.
4. **Après un mois** : regarder dans GA4 les visites de la page et les événements `generate_lead` avec `lead_type = maturite`.

## Idées de suites

- Un post par déséquilibre (« des usages en avance sur le cadre », « des outils fournis, peu de formation ») : chacun renvoie vers le test.
- Une version du post par secteur prioritaire (expertise comptable, droit, santé).
- Proposer le test en amont d’un pré-audit : le résultat sert d’ordre du jour.
