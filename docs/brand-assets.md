# Logos du bandeau partagé

Le composant `components/brand/TrustStrip.tsx` présente les partenaires et, sur une ligne distincte, les outils IA utilisés dans les missions. La présence d’un outil ne signifie pas un partenariat officiel avec son éditeur.

- **Claude** : icône SVG existante, `public/logos/claude.svg`.
- **ChatGPT** : symbole OpenAI noir issu du [kit officiel OpenAI](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip), fichier `OpenAI-logos(new)/SVGs/OpenAI-black-monoblossom.svg`. Copie inchangée dans `public/logos/chatgpt.svg`.
- **Mistral** : icône SVG du bandeau mobile de la [page de marque officielle](https://mistral.ai/brand/), copie inchangée dans `public/logos/mistral.svg`.

Ajout le 8 octobre 2026. Les noms sont affichés à côté des symboles ; les images sont décoratives pour éviter une double annonce par les lecteurs d’écran. Les partenaires existants disposent chacun d’un texte alternatif nominatif.
